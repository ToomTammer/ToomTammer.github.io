Livestock Module 2/7 · Breeding & Gestation — Dev-Ready Spec

โมดูลผสมพันธุ์และตั้งท้อง (Breeding & Gestation)

สเปกสำหรับเริ่มพัฒนาได้ทันที ครอบคลุมขอบเขตและจุดเชื่อมต่อกับโมดูลอื่น ฟังก์ชันหลักแยก MVP กับที่เพิ่มทีหลังได้ โครงสร้างฐานข้อมูล API หลักที่ต้องมี สิทธิ์การเข้าถึงตามบทบาท และสูตรคำนวณ/กฎทางธุรกิจ

ส่วนหนึ่งของ คู่มือ ERP สำหรับธุรกิจฟาร์ม อัปเดต 18 ก.ค. 2569
1. ขอบเขตและจุดเชื่อมต่อ (Scope & Integration) 2. ฟังก์ชันหลัก (Core Functions) 3. ฐานข้อมูล (Database) 4. API 5. สิทธิ์การเข้าถึง (Roles) 6. สูตรคำนวณ (Formulas) 7. หน้าจอที่ต้องมี (Screens)
Scope & Integration

1. ขอบเขตและจุดเชื่อมต่อ (Scope & Integration Points)

โมดูลนี้ติดตามวงจรการขยายพันธุ์ตั้งแต่ผสมจนถึงคลอด แล้วส่งต่อให้โมดูลทะเบียนสัตว์สร้างทะเบียนใหม่ให้ลูกที่เกิดแต่ละตัวโดยอัตโนมัติ

อยู่ในขอบเขต

  • บันทึกการผสมพันธุ์ (Breeding Event) — ผสมธรรมชาติหรือผสมเทียม
  • ติดตามการตั้งท้อง (Pregnancy Tracking)
  • บันทึกการคลอด (Calving/Farrowing Record)
  • ประวัติสายพันธุ์/เชื้อสาย (Pedigree)
  • ปฏิทินผสมพันธุ์/กำหนดคลอดรวมทั้งฟาร์ม

อยู่นอกขอบเขต (รับ/ส่งข้อมูลกับโมดูลอื่น)

  • ทะเบียนแม่พันธุ์/พ่อพันธุ์ — รับจาก ทะเบียนสัตว์
  • การสร้างทะเบียนสัตว์ใหม่เมื่อคลอด — ส่งต่อให้ ทะเบียนสัตว์
  • ประวัติสุขภาพระหว่างตั้งท้อง/หลังคลอด — ส่งต่อให้ สุขภาพและวัคซีน
  • น้ำหนัก/การเจริญเติบโตของลูกหลังคลอด — ส่งต่อให้ การเจริญเติบโตและผลผลิต
โมดูลที่เกี่ยวข้องเหตุการณ์สิ่งที่ผสมพันธุ์ฯ ต้องทำPhase
ทะเบียนสัตว์มีแม่พันธุ์/พ่อพันธุ์พร้อมผสมดึงมาบันทึกการผสมพันธุ์Phase 1
ผสมพันธุ์ฯ (ตัวเอง) → ทะเบียนสัตว์คลอดสำเร็จสร้างทะเบียนสัตว์ใหม่ผูกกับพ่อแม่พันธุ์ต่อลูกแต่ละตัวPhase 1
การเจริญเติบโตและผลผลิตต้องการน้ำหนักแรกเกิดตั้งต้นให้ birth_weight จากบันทึกการคลอดอ้างอิงPhase 1
สุขภาพและวัคซีนต้องการประวัติการตั้งท้องเพื่อดูแลสุขภาพให้ pregnancy อ้างอิงPhase 2
Core Functions

2. ฟังก์ชันหลัก (Core Functions)

แยกชัดว่าอะไรต้องใช้งานได้ตั้งแต่วันแรก (MVP) และอะไรเพิ่มทีหลังได้โดยไม่กระทบการติดตามวงจรผสมพันธุ์พื้นฐาน

MVP — ต้องมีวันแรก Phase 1

  • บันทึกการผสมพันธุ์ (วันที่ วิธีผสม พ่อพันธุ์)
  • บันทึกผลตรวจท้อง และคำนวณวันครบกำหนดคลอดอัตโนมัติ
  • บันทึกการคลอด (จำนวนลูก น้ำหนักแรกเกิด) พร้อมสร้างทะเบียนสัตว์ใหม่อัตโนมัติ
  • ดูปฏิทินผสมพันธุ์/กำหนดคลอดรวมทั้งฟาร์ม
  • บันทึกประวัติสายพันธุ์ (พ่อแม่พันธุ์) ต่อสัตว์ใหม่ที่เกิด

เพิ่มทีหลังได้

  • แจ้งเตือนอัตโนมัติเมื่อใกล้ถึงวันคลอดPhase 2
  • คำนวณอัตราความสำเร็จการผสมพันธุ์ต่อพ่อพันธุ์/วิธีผสมPhase 2
  • ดูสายเลือดย้อนหลังหลายชั่วอายุ (pedigree tree)Phase 2
  • แนะนำคู่ผสมพันธุ์ที่เหมาะสมเพื่อลดการผสมเลือดชิดPhase 3
  • พยากรณ์ผลผลิตน้ำนม/เนื้อจากสายพันธุ์ที่จะผสมPhase 3
Database

3. ฐานข้อมูล (Database)

แต่ละเอนทิตีคือ 1 ตารางในฐานข้อมูล พร้อมคำอธิบายว่าแทนอะไรในโลกจริง และแต่ละฟิลด์เก็บอะไร ชนิดข้อมูลแบบไหน

breeding_record Phase 1

บันทึกการผสมพันธุ์ — บันทึกเหตุการณ์ผสมพันธุ์แต่ละครั้ง ทั้งผสมธรรมชาติและผสมเทียม

ความสัมพันธ์: ผูกกับ animal สองตัว (แม่พันธุ์และพ่อพันธุ์) จากโมดูลทะเบียนสัตว์ เป็นต้นทางให้ pregnancy

ฟิลด์ชนิดข้อมูลเก็บอะไร
idเลขอ้างอิง/UUID (PK)รหัสประจำแถวนี้ ไม่ซ้ำกัน สร้างอัตโนมัติ
dam_idเลขอ้างอิง (FK → animal)แม่พันธุ์ตัวไหน
sire_idเลขอ้างอิง (FK → animal, ว่างได้)พ่อพันธุ์ตัวไหน ถ้าเป็นพ่อพันธุ์ของฟาร์มเอง
sire_semen_refข้อความ (text, ว่างได้)รหัสอ้างอิงน้ำเชื้อ ถ้าผสมเทียมจากภายนอก
breeding_dateวันที่ (date)วันที่ผสมพันธุ์
methodตัวเลือกคงที่ (enum)วิธีผสม เลือกได้เฉพาะ: natural, artificial_insemination
statusตัวเลือกคงที่ (enum)สถานะ เลือกได้เฉพาะ: pending, confirmed_pregnant, not_pregnant, failed

pregnancy Phase 1

การตั้งท้อง — ติดตามการตั้งท้องหลังผสมพันธุ์สำเร็จ จนถึงคลอดหรือแท้ง

ความสัมพันธ์: ผูกกับ breeding_record หนึ่งรายการ เป็นต้นทางให้ calving_record

ฟิลด์ชนิดข้อมูลเก็บอะไร
idเลขอ้างอิง/UUID (PK)รหัสประจำแถวนี้ ไม่ซ้ำกัน สร้างอัตโนมัติ
breeding_record_idเลขอ้างอิง (FK → breeding_record)ท้องนี้มาจากการผสมพันธุ์ครั้งไหน
confirmed_dateวันที่ (date)วันที่ตรวจยืนยันว่าท้อง
expected_due_dateวันที่ (date)วันครบกำหนดคลอดโดยประมาณ คำนวณจากวันผสมพันธุ์+ระยะตั้งท้องของชนิดสัตว์
statusตัวเลือกคงที่ (enum)สถานะ เลือกได้เฉพาะ: ongoing, delivered, aborted

calving_record Phase 1

บันทึกการคลอด — บันทึกผลการคลอดจริง จำนวนลูกที่เกิด เป็นจุดที่นำไปสร้างทะเบียนสัตว์ใหม่ต่อ

ความสัมพันธ์: ผูกกับ pregnancy หนึ่งรายการ และมี offspring_record หลายตัวต่อการคลอดหนึ่งครั้ง

ฟิลด์ชนิดข้อมูลเก็บอะไร
idเลขอ้างอิง/UUID (PK)รหัสประจำแถวนี้ ไม่ซ้ำกัน สร้างอัตโนมัติ
pregnancy_idเลขอ้างอิง (FK → pregnancy)เป็นผลของการตั้งท้องครั้งไหน
calving_dateวันที่ (date)วันที่คลอดจริง
live_birth_count / stillbirth_countตัวเลข (integer)จำนวนลูกที่รอด และจำนวนที่ตายคลอด
complicationsข้อความ (text, ว่างได้)ภาวะแทรกซ้อนระหว่างคลอด ถ้ามี

offspring_record Phase 1

บันทึกลูกแต่ละตัว — รายละเอียดลูกแต่ละตัวที่เกิดจากการคลอดครั้งนี้ ใช้ผูกไปสร้างทะเบียนสัตว์ใหม่ในโมดูลทะเบียนสัตว์

ความสัมพันธ์: ผูกกับ calving_record และเป็นต้นทางสร้าง animal ใหม่ผ่าน new_animal_ref

ฟิลด์ชนิดข้อมูลเก็บอะไร
idเลขอ้างอิง/UUID (PK)รหัสประจำแถวนี้ ไม่ซ้ำกัน สร้างอัตโนมัติ
calving_record_idเลขอ้างอิง (FK → calving_record)เป็นลูกจากการคลอดครั้งไหน
birth_weightตัวเลข (decimal)น้ำหนักแรกเกิด
sexตัวเลือกคงที่ (enum)เพศ เลือกได้เฉพาะ: male, female
new_animal_refข้อความ (text, ว่างได้)เลขอ้างอิงทะเบียนสัตว์ใหม่ที่สร้างในโมดูลทะเบียนสัตว์สำหรับลูกตัวนี้
API

4. API

Endpoint หลักที่ต้องมีสำหรับ MVP (Phase 1) และที่ตามมาใน Phase 2

MethodEndpointคำอธิบายPhase
GET/livestock/breeding-recordsดึงประวัติการผสมพันธุ์ (filter: dam_id, status, date_from, date_to) — ดึงจาก breeding_record1
POST/livestock/breeding-recordsบันทึกการผสมพันธุ์ใหม่ — บันทึกลง breeding_record (อ้างอิง dam_id, sire_id จากโมดูลทะเบียนสัตว์)1
PATCH/livestock/breeding-records/{id}อัปเดตผลตรวจ (confirmed_pregnant/not_pregnant/failed) — บันทึกลง breeding_record (อัปเดตฟิลด์ status)1
GET/livestock/pregnanciesดึงรายการตั้งท้องทั้งหมด — ดึงจาก pregnancy, breeding_record1
POST/livestock/pregnanciesสร้างรายการติดตามการตั้งท้อง — บันทึกลง pregnancy (อ้างอิง breeding_record_id จาก breeding_record)1
POST/livestock/pregnancies/{id}/calvingบันทึกการคลอด สร้าง offspring_record และทะเบียนสัตว์ใหม่อัตโนมัติ — บันทึกลง calving_record (อ้างอิง pregnancy_id จาก pregnancy), offspring_record (อ้างอิง calving_record_id) และเรียกโมดูลทะเบียนสัตว์ให้สร้าง animal ใหม่ต่อลูกแต่ละตัว แล้วเก็บอ้างอิงกลับไว้ที่ offspring_record.new_animal_ref1
GET/livestock/calving-recordsดึงประวัติการคลอดทั้งหมด — ดึงจาก calving_record, offspring_record1
GET/livestock/animals/{id}/pedigreeดูสายเลือดย้อนหลังของสัตว์ตัวหนึ่ง — ดึงจาก offspring_record (หา breeding_record ต้นทางของสัตว์ตัวนี้ผ่าน new_animal_ref), breeding_record (ไล่ dam_id/sire_id ย้อนหลายชั่วอายุ) และชื่อ/รหัสสัตว์จากโมดูลทะเบียนสัตว์1
GET/livestock/reports/breeding-calendarปฏิทินผสมพันธุ์/กำหนดคลอดรวมทั้งฟาร์ม — ดึงจาก breeding_record (breeding_date), pregnancy (expected_due_date)1
GET/livestock/reports/conception-rateอัตราความสำเร็จการผสมพันธุ์ต่อพ่อพันธุ์/วิธีผสม — ดึงจาก breeding_record ตามสูตร conception_rate_pct (หัวข้อ 6)2

Business Rules & Formulas

6. สูตรคำนวณและกฎทางธุรกิจ (Business Rules & Formulas)

ตรรกะที่ dev ต้อง implement จริงเบื้องหลัง entity/endpoint ด้านบน

คำนวณวันครบกำหนดคลอด (Expected Due Date)

Phase 1

ระยะตั้งท้องต่างกันตามชนิดสัตว์ ต้องตั้งเป็นค่าปรับได้ต่อสายพันธุ์

expected_due_date =
  breeding_date + gestation_period_days

ตัวอย่างระยะตั้งท้องมาตรฐาน:
  วัว     ~ 283 วัน
  สุกร    ~ 114 วัน
  แพะ/แกะ ~ 150 วัน

อัตราความสำเร็จการผสมพันธุ์ (Conception Rate)

Phase 2

ใช้ประเมินประสิทธิภาพพ่อพันธุ์หรือวิธีผสมที่ใช้

conception_rate_pct =
  COUNT(breeding_record WHERE status = confirmed_pregnant)
  / COUNT(breeding_record ทั้งหมดของช่วงเวลา/พ่อพันธุ์นั้น)
  × 100

อัตราการเกิดรอด (Live Birth Rate)

Phase 1

คำนวณทันทีที่บันทึก calving_record

live_birth_rate_pct =
  live_birth_count
  / (live_birth_count + stillbirth_count)
  × 100

ตรวจสอบเลือดชิดก่อนอนุมัติผสมพันธุ์ (Inbreeding Check)

Phase 3

ป้องกันปัญหาสุขภาพและคุณภาพสายพันธุ์ระยะยาว

shared_ancestor_check(dam, sire) =
  ตรวจว่า dam และ sire มีบรรพบุรุษร่วมกัน
  ภายใน N ชั่วอายุ (เช่น 3 ชั่วอายุ) จาก pedigree

ถ้าพบ -> flag เตือนความเสี่ยงผสมเลือดชิด
  ก่อนยืนยันบันทึกการผสมพันธุ์

แจ้งเตือนใกล้ถึงกำหนดคลอด (Calving Due Soon Alert)

Phase 2

ให้ทีมงานเตรียมพร้อมดูแลการคลอดล่วงหน้า

days_to_due = expected_due_date - today

flag เตือนถ้า days_to_due <= alert_lead_days
  (ค่าเริ่มต้นแนะนำ: 7 วัน)
Screens

7. หน้าจอที่ต้องมี (Screens/Pages)

รายชื่อหน้าจอที่ต้องมีจริงในโมดูลนี้ พร้อมส่วนประกอบหลักของแต่ละหน้า — ใช้เป็น checklist ออกแบบ UI ต่อได้ตรง ๆ ไม่ต้องนั่งไล่จากฟังก์ชัน/entity เอง

แดชบอร์ดผสมพันธุ์และตั้งท้อง (Breeding & Pregnancy Dashboard) Phase 1

หน้าแรกที่เจ้าหน้าที่ผสมพันธุ์/สัตวบาลเปิดดูภาพรวมวงจรผสมพันธุ์ประจำวัน

  • การ์ดสรุป: จำนวนตัวที่กำลังตั้งท้อง (pregnancy.status = ongoing), จำนวนที่ใกล้ครบกำหนดคลอด, อัตราตั้งท้องสำเร็จเดือนนี้
  • รายการแจ้งเตือนสั้น ๆ: ตัวที่ days_to_due <= alert_lead_days
  • ทางลัดไปหน้า "บันทึกการผสมพันธุ์ใหม่" และปฏิทินผสมพันธุ์รวม

รายการบันทึกการผสมพันธุ์ (Breeding Records) Phase 1

ดูและติดตามบันทึกการผสมพันธุ์ทุกครั้งของฟาร์ม

  • ตารางรายการ: dam_id, sire_id/sire_semen_ref, breeding_date, method, status พร้อม badge สีตามสถานะ
  • ตัวกรอง: dam_id, status (pending/confirmed_pregnant/not_pregnant/failed), date_from–date_to
  • ปุ่ม "บันทึกการผสมพันธุ์ใหม่" เปิดฟอร์มสร้างรายการ
  • คลิกแถวเพื่ออัปเดตผลตรวจ (PATCH /livestock/breeding-records/{id})

ฟอร์มบันทึกการผสมพันธุ์ใหม่ (New Breeding Record Form) Phase 1

คีย์ข้อมูลการผสมพันธุ์แต่ละครั้งให้ครบก่อนส่งเข้าระบบ

  • เลือกแม่พันธุ์ (dam_id) จากทะเบียนสัตว์
  • สลับกรอกพ่อพันธุ์ของฟาร์ม (sire_id) หรือรหัสน้ำเชื้อภายนอก (sire_semen_ref) ตาม method
  • เลือก breeding_date และ method (natural/artificial_insemination)
  • แจ้งเตือนความเสี่ยงเลือดชิด (inbreeding check) ก่อนกดยืนยันบันทึก Phase 3

รายการตั้งท้อง (Pregnancy List) Phase 1

ติดตามตัวที่ยืนยันตั้งท้องแล้วทั้งหมด จนถึงคลอดหรือแท้ง

  • ตารางรายการ: breeding_record_id (พร้อมชื่อ/รหัสแม่พันธุ์), confirmed_date, expected_due_date, status
  • ตัวกรองตามสถานะ (ongoing/delivered/aborted) และช่วง expected_due_date
  • ปุ่ม "บันทึกผลตรวจท้อง" สร้างรายการ pregnancy ใหม่จาก breeding_record ที่เลือก
  • คลิกแถวเพื่อดูหน้ารายละเอียดการตั้งท้อง

รายละเอียดการตั้งท้อง (Pregnancy Detail) Phase 1

ดูข้อมูลครบของท้องนี้ก่อนตัดสินใจบันทึกการคลอด

  • ข้อมูลอ้างอิงจาก breeding_record: dam, sire/sire_semen_ref, breeding_date, method
  • นับถอยหลังวันครบกำหนดคลอด (expected_due_date) พร้อมสถานะ ongoing/delivered/aborted
  • ปุ่ม "บันทึกการคลอด" (POST /livestock/pregnancies/{id}/calving) หรือ "บันทึกแท้ง" เปลี่ยน status เป็น aborted

ฟอร์มบันทึกการคลอด (Calving Record Form) Phase 1

บันทึกผลคลอดจริงพร้อมข้อมูลลูกแต่ละตัวในครั้งเดียว

  • กรอก calving_date, live_birth_count, stillbirth_count, complications (ถ้ามี)
  • รายการย่อยเพิ่มลูกแต่ละตัว (offspring_record): birth_weight, sex ต่อแถว
  • ปุ่ม "บันทึกการคลอด" เรียก POST /livestock/pregnancies/{id}/calving สร้าง calving_record + offspring_record และทะเบียนสัตว์ใหม่ (new_animal_ref) ต่อลูกแต่ละตัวอัตโนมัติ

ประวัติการคลอด (Calving Records History) Phase 1

ดูผลคลอดย้อนหลังทั้งหมดพร้อมอัตราการเกิดรอด

  • ตารางรายการ: pregnancy_id, calving_date, live_birth_count, stillbirth_count, live_birth_rate_pct ที่คำนวณอัตโนมัติ
  • ตัวกรองตามช่วงวันที่คลอด
  • คลิกแถวดูรายการ offspring_record และลิงก์ไปทะเบียนสัตว์ใหม่ (new_animal_ref) ของลูกแต่ละตัว

ปฏิทินผสมพันธุ์/กำหนดคลอด (Breeding & Due Date Calendar) Phase 1

ภาพรวมกำหนดการผสมพันธุ์และคลอดทั้งฟาร์มในหน้าเดียว

  • มุมมองปฏิทินรายเดือน แสดง breeding_date และ expected_due_date เป็นจุดกิจกรรมคนละสี
  • ตัวกรองช่วงวันที่ ดึงจาก GET /livestock/reports/breeding-calendar
  • คลิกวันที่เพื่อดูรายการ breeding_record/pregnancy ของวันนั้น

สายเลือด/เชื้อสาย (Pedigree Viewer) Phase 1

ดูสายเลือดย้อนหลังของสัตว์ตัวหนึ่ง ก่อนตัดสินใจคู่ผสมครั้งต่อไป

  • แผนผังต้นไม้สายเลือด (pedigree tree) จาก GET /livestock/animals/{id}/pedigree
  • ไล่ดูย้อนหลังหลายชั่วอายุ (dam/sire ของ dam/sire) Phase 2
  • ช่องค้นหาสัตว์ตัวอื่นเพื่อสลับดูสายเลือด

รายงานอัตราความสำเร็จการผสมพันธุ์ (Conception Rate Report) Phase 2

ประเมินประสิทธิภาพพ่อพันธุ์หรือวิธีผสมที่ใช้

  • ตาราง/กราฟ conception_rate_pct แยกตาม sire_id และ method จาก GET /livestock/reports/conception-rate
  • ตัวกรองช่วงวันที่และพ่อพันธุ์

แจ้งเตือนใกล้ถึงกำหนดคลอด (Calving Due Soon Alerts) Phase 2

รายการตัวที่ใกล้ครบกำหนดคลอด ให้ทีมงานเตรียมพร้อมล่วงหน้า

  • รายการ pregnancy ที่ days_to_due (= expected_due_date − วันนี้) ≤ alert_lead_days (ค่าเริ่มต้น 7 วัน)
  • ตั้งค่า alert_lead_days ได้ต่อฟาร์ม/ชนิดสัตว์
  • คลิกแถวเพื่อไปหน้ารายละเอียดการตั้งท้อง

ตรวจสอบเลือดชิดก่อนอนุมัติผสมพันธุ์ (Inbreeding Check) Phase 3

ป้องกันปัญหาสุขภาพและคุณภาพสายพันธุ์ระยะยาวก่อนยืนยันคู่ผสม

  • แสดงผล shared_ancestor_check(dam, sire) พร้อม flag เตือนถ้าพบบรรพบุรุษร่วมภายใน N ชั่วอายุจาก pedigree
  • แสดงเป็นกล่องเตือนแทรกในฟอร์มบันทึกการผสมพันธุ์ใหม่ ก่อนกดยืนยัน
