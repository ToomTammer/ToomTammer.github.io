โมดูลอาหารสัตว์ (Feed Management)

สเปกสำหรับเริ่มพัฒนาได้ทันที ครอบคลุมขอบเขตและจุดเชื่อมต่อกับโมดูลอื่น ฟังก์ชันหลักแยก MVP กับที่เพิ่มทีหลังได้ โครงสร้างฐานข้อมูล API หลักที่ต้องมี สิทธิ์การเข้าถึงตามบทบาท และสูตรคำนวณ/กฎทางธุรกิจ

ส่วนหนึ่งของ คู่มือ ERP สำหรับธุรกิจฟาร์ม อัปเดต 18 ก.ค. 2569
1. ขอบเขตและจุดเชื่อมต่อ (Scope & Integration) 2. ฟังก์ชันหลัก (Core Functions) 3. ฐานข้อมูล (Database) 4. API 5. สิทธิ์การเข้าถึง (Roles) 6. สูตรคำนวณ (Formulas)
Scope & Integration

1. ขอบเขตและจุดเชื่อมต่อ (Scope & Integration Points)

โมดูลนี้จัดการสูตรอาหารตามช่วงอายุและบันทึกการให้อาหารจริง แล้วรวมกับน้ำหนักจากโมดูลการเจริญเติบโตเพื่อคำนวณ FCR ซึ่งเป็น KPI สำคัญที่สุดของฟาร์มปศุสัตว์

อยู่ในขอบเขต

  • สูตรอาหารตามช่วงอายุ (Feed Formula by Stage)
  • บันทึกการให้อาหารประจำวัน (Feeding Record)
  • คำนวณอัตราแลกเนื้อ (FCR)
  • ตารางให้อาหารตามแผน (Feeding Schedule)
  • ติดตามต้นทุนอาหารต่อตัว/ฝูง

อยู่นอกขอบเขต (รับ/ส่งข้อมูลกับโมดูลอื่น)

  • ทะเบียนสัตว์/ฝูง — รับจาก ทะเบียนสัตว์
  • การตัดสต็อกอาหารสัตว์ที่ใช้จริง — ส่งต่อให้ คลังสินค้า/สต็อก
  • น้ำหนักที่ใช้คำนวณ FCR — รับจาก การเจริญเติบโตและผลผลิต
  • ต้นทุนอาหารเข้ารอบผลิต — สะท้อนผ่าน COGS ที่คลังตัดแล้ว ไม่คำนวณเอง
โมดูลที่เกี่ยวข้องเหตุการณ์สิ่งที่อาหารสัตว์ต้องทำPhase
ทะเบียนสัตว์มีสัตว์/ฝูงพร้อมให้อาหารอ้างอิง animal_id/animal_group_idPhase 1
อาหารสัตว์ (ตัวเอง) → คลังสินค้า/สต็อกบันทึกให้อาหารจริงแจ้งตัดสต็อกอาหารสัตว์ที่ใช้Phase 1
การเจริญเติบโตและผลผลิตมีน้ำหนักที่ชั่งได้ล่าสุดดึงมาคำนวณ FCR ร่วมกับปริมาณอาหารที่ให้Phase 1
จัดซื้อสต็อกอาหารใกล้หมดตามแผนให้อาหารเสนอสร้างใบขอซื้ออาหารล่วงหน้าPhase 2
Core Functions

2. ฟังก์ชันหลัก (Core Functions)

แยกชัดว่าอะไรต้องใช้งานได้ตั้งแต่วันแรก (MVP) และอะไรเพิ่มทีหลังได้โดยไม่กระทบการให้อาหารพื้นฐาน

MVP — ต้องมีวันแรก Phase 1

  • ตั้งสูตรอาหารตามช่วงอายุต่อชนิดสัตว์
  • บันทึกการให้อาหารประจำวัน พร้อมแจ้งตัดสต็อก
  • คำนวณอัตราแลกเนื้อ (FCR) ต่อฝูง/รอบผลิต
  • ดูต้นทุนอาหารสะสมต่อตัว/ฝูง
  • ดูแผนการให้อาหารตามช่วงอายุที่ควรเปลี่ยนสูตร

เพิ่มทีหลังได้

  • แจ้งเตือนอัตโนมัติเมื่อถึงช่วงอายุที่ควรเปลี่ยนสูตรอาหารPhase 2
  • เชื่อมกับจุดสั่งซื้อซ้ำอาหารสัตว์ตามแผนล่วงหน้าPhase 2
  • เปรียบเทียบ FCR ระหว่างฝูง/สูตรอาหารต่างกันPhase 2
  • เชื่อมเครื่องให้อาหารอัตโนมัติ (IoT feeder) บันทึกปริมาณจริงPhase 3
  • พยากรณ์ต้นทุนอาหารล่วงหน้าจากแผนการเลี้ยงทั้งรอบPhase 3
Database

3. ฐานข้อมูล (Database)

แต่ละเอนทิตีคือ 1 ตารางในฐานข้อมูล พร้อมคำอธิบายว่าแทนอะไรในโลกจริง และแต่ละฟิลด์เก็บอะไร ชนิดข้อมูลแบบไหน

feed_formula Phase 1

สูตรอาหาร — กำหนดสูตรอาหารที่ควรใช้ตามช่วงอายุของสัตว์แต่ละชนิด เช่น อาหารลูกไก่ (starter) อาหารไก่รุ่น (grower) อาหารไก่ไข่ (finisher)

ความสัมพันธ์: ผูกกับ species (จากโมดูลทะเบียนสัตว์) และ item (อาหารสัตว์จากโมดูลคลังสินค้า)

ฟิลด์ชนิดข้อมูลเก็บอะไร
speciesข้อความ/ตัวเลือกคงที่ (enum)สูตรนี้ใช้กับสัตว์ชนิดไหน
stage_nameข้อความ (text)ชื่อช่วงอายุ เช่น starter, grower, finisher
age_days_start / age_days_endตัวเลข (integer)ช่วงอายุเป็นวันที่ใช้สูตรนี้
feed_item_idเลขอ้างอิง (FK → item)ใช้อาหารชนิดไหนจากคลังสินค้า
daily_amount_per_headตัวเลข (decimal)ปริมาณอาหารแนะนำต่อตัวต่อวัน

feeding_record Phase 1

บันทึกการให้อาหาร — บันทึกการให้อาหารจริงประจำวันต่อสัตว์หรือฝูง

ความสัมพันธ์: ผูกกับ animal/animal_group และ item (อาหารจากโมดูลคลังสินค้า) ที่ถูกตัดสต็อก

ฟิลด์ชนิดข้อมูลเก็บอะไร
animal_id / animal_group_idเลขอ้างอิง (FK)ให้อาหารสัตว์ตัวไหนหรือฝูงไหน
feed_item_idเลขอ้างอิง (FK → item)ใช้อาหารชนิดไหนจากคลังสินค้า
feeding_dateวันที่ (date)วันที่ให้อาหารจริง
quantity_givenตัวเลข (decimal)ปริมาณอาหารที่ให้จริง
fed_byเลขอ้างอิง (FK → user)ใครเป็นคนให้อาหาร

fcr_calculation Phase 1

การคำนวณอัตราแลกเนื้อ — บันทึกผลคำนวณ FCR ต่อฝูงในแต่ละช่วงเวลา/รอบผลิต โดยรวมปริมาณอาหารที่ให้กับน้ำหนักที่เพิ่มขึ้น

ความสัมพันธ์: ผูกกับ animal_group และดึงข้อมูลน้ำหนักจากโมดูลการเจริญเติบโตและผลผลิต

ฟิลด์ชนิดข้อมูลเก็บอะไร
animal_group_idเลขอ้างอิง (FK → animal_group)คำนวณ FCR ของฝูงไหน
period_start / period_endวันที่ (date)ช่วงเวลาที่คำนวณ
total_feed_consumedตัวเลข (decimal)ปริมาณอาหารรวมที่ใช้ในช่วงนี้
total_weight_gainตัวเลข (decimal)น้ำหนักที่เพิ่มขึ้นรวมในช่วงนี้ ดึงจากโมดูลการเจริญเติบโต
fcr_valueตัวเลข (decimal)ค่า FCR ที่คำนวณได้ = total_feed_consumed / total_weight_gain

feeding_schedule Phase 2

ตารางให้อาหารตามแผน — กำหนดการให้อาหารตามช่วงเวลาที่วางแผนไว้ล่วงหน้า เช่น ให้อาหารวันละ 2 มื้อ เวลาเท่าไหร่ ใช้เตือนพนักงานหน้างาน

ความสัมพันธ์: ผูกกับ animal_group และ feed_formula ที่ควรใช้ในมื้อนั้น

ฟิลด์ชนิดข้อมูลเก็บอะไร
animal_group_idเลขอ้างอิง (FK → animal_group)ตารางนี้เป็นของฝูงไหน
feeding_timeเวลา (time)เวลาที่ควรให้อาหารในแต่ละวัน
feed_formula_idเลขอ้างอิง (FK → feed_formula)มื้อนี้ควรใช้สูตรอาหารไหน
statusตัวเลือกคงที่ (enum)สถานะ เลือกได้เฉพาะ: scheduled, completed, skipped

Business Rules & Formulas

6. สูตรคำนวณและกฎทางธุรกิจ (Business Rules & Formulas)

ตรรกะที่ dev ต้อง implement จริงเบื้องหลัง entity/endpoint ด้านบน

คำนวณอัตราแลกเนื้อ (FCR)

Phase 1

KPI สำคัญที่สุดของฟาร์มปศุสัตว์ ยิ่งค่าต่ำยิ่งมีประสิทธิภาพดี

fcr_value = total_feed_consumed / total_weight_gain

ตัวอย่าง: ใช้อาหาร 1,800 กก. ได้น้ำหนักเพิ่ม 1,000 กก.
  -> FCR = 1.8 (ใช้อาหาร 1.8 กก. ต่อน้ำหนักที่เพิ่ม 1 กก.)

เลือกสูตรอาหารที่เหมาะสมตามอายุ

Phase 1

ใช้แนะนำสูตรที่ถูกต้องให้พนักงานหน้างานโดยอัตโนมัติ

current_feed_formula(animal_group) =
  feed_formula ที่ species ตรงกัน
  AND age_days_start <= current_age_days <= age_days_end

ต้นทุนอาหารสะสมต่อตัว

Phase 1

ใช้ต้นทุนจริงของล็อตอาหารที่ตัดสต็อก ไม่ใช่ราคาประมาณ

feed_cost_per_head(animal_group) =
  SUM(feeding_record.quantity_given × unit_cost ของ lot ที่ตัด)
  / current_quantity ของฝูง

เตือนเปลี่ยนสูตรอาหารตามช่วงอายุ

Phase 2

ป้องกันการให้อาหารผิดสูตรเมื่อสัตว์โตเกินช่วงอายุที่กำหนด

ถ้า current_age_days > feed_formula.age_days_end
   ของสูตรที่ใช้อยู่ตอนนี้

-> flag เตือนให้เปลี่ยนสูตรอาหารตามที่กำหนดไว้

เปรียบเทียบ FCR กับค่ามาตรฐาน (FCR Benchmark)

Phase 2

ใช้ประเมินว่ารอบนี้เลี้ยงได้ดีกว่าหรือแย่กว่าปกติ

fcr_variance_pct =
  (current_fcr - benchmark_fcr) / benchmark_fcr × 100

benchmark_fcr = FCR เฉลี่ยของฝูงก่อนหน้า
  ที่ใช้สูตรอาหารเดียวกัน หรือค่ามาตรฐานอุตสาหกรรม

หมายเหตุ: variance เป็นบวกแปลว่าใช้อาหารมากกว่าปกติเพื่อผลผลิตเท่าเดิม (แย่ลง) ควรตรวจสอบคุณภาพอาหาร/สุขภาพฝูงประกอบ
